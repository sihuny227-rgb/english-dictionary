# 나만의 영어 사전 · 휴대폰 앱 버전

영어 단어를 찾으면 뜻과 예문 3개를 찾아 **단어장에 자동으로 저장**하고, 발음 듣기·퀴즈·단어 알림으로 외우는 앱입니다.
'영어 공부 루틴'과 같은 방식의 웹앱(PWA)이라 앱스토어 없이 휴대폰 홈 화면에 설치할 수 있고, 한 번 연 뒤에는 인터넷 없이도 단어장과 퀴즈를 쓸 수 있습니다 (새 단어 찾기만 인터넷이 필요해요).

## 할 수 있는 것

| 화면 | 하는 일 |
|---|---|
| 사전 | 단어를 치면 뜻·발음 기호·예문 3개(한국어 해석 포함)를 찾아 단어장에 저장. 한글로 쳐도 돼요 (사과 → apple). 스피커 버튼을 누르면 단어나 문장을 읽어 줘요 |
| 단어장 | 저장한 단어 찾기, 정렬(최근·ABC·복습 가까운 순·약한 단어), 수정, 삭제 |
| 퀴즈 | 영어 → 뜻 / 한글 → 영어(직접 쓰기, 힌트 있음) / 빈칸 채우기 / 섞어서 |
| 설정 | 단어 알림, 뜻 찾는 방법(무료 사전·AI), 목소리·빠르기, 문제 수, 백업 |

### 퀴즈 간격 (잘 아는 단어는 덜, 모르는 단어는 더 자주)

- 맞히면 그 단어의 다음 퀴즈까지 간격이 늘어나요: 4시간 → 1일 → 3일 → 1주 → 3주 → 2개월 …
- 틀리면 10분 뒤에 다시 나오고, 그 단어의 '쉬움 점수'가 내려가서 앞으로도 간격이 천천히 늘어나요. 자주 틀린 단어일수록 더 자주 나와요.
- 힌트를 보고 맞히면 조금만 늘어나요. 틀린 단어는 그 퀴즈 끝에 한 번 더 나와요.
- 퀴즈 탭의 숫자가 지금 복습할 차례가 된 단어 수예요.

### 단어 알림

설정에서 켜면 정해진 간격(15분~4시간)마다, 정한 시간대 안에서 단어장의 단어 하나를 예문 3개와 함께 보여 줘요. 덜 외운 단어가 더 자주 나와요.

- **앱을 열어 둔 동안에만 알림이 와요.** 웹앱은 닫힌 상태에서 스스로 알림을 띄우지 못해요.
- 앱을 보고 있으면 화면에 단어 카드가 뜨고, 앱을 잠깐 다른 화면으로 내려 두면 휴대폰 알림으로 와요 (휴대폰 알림을 허용한 경우). 알림을 누르면 그 단어가 열려요.
- 앱을 닫아 둔 사이에 지난 알림은 다음에 앱을 열 때 한 번만 보여 줘요.
- 아이폰은 홈 화면에 추가한 앱에서만 휴대폰 알림이 돼요 (iOS 16.4 이상).

## 뜻·예문은 어디서 오나요?

기본은 **무료 사전**이에요. 가입이나 키 없이 바로 써요.

- **한국어 뜻:** 사람이 쓴 사전인 **위키낱말사전**(ko.wiktionary.org, CC BY-SA)에서 품사별로 가져와요 (예: reluctant → 마음이 내키지 않는, 꺼리는). 없으면 영어 위키낱말사전(en.wiktionary.org)의 뜻별 한국어 번역을 쓰고, 둘 다 없을 때만 기계 번역(MyMemory)으로 채워요. 단어 카드에 '뜻 출처'가 나와요. apples·went처럼 변화형을 치면 원형(apple·go)으로 찾아요.
- **예문:** 위키낱말사전, dictionaryapi.dev, Tatoeba에서 모은 문장 가운데 점수가 높은 3개를 골라요. 단어가 모양 그대로 들어 있고, 사람이 번역한 해석이 있고, 7~14단어인 문장이 먼저예요. Tom·Mary 같은 이름이 들어간 문장, 'to be eager to something' 같은 문형 설명, 거의 같은 문장은 뒤로 미뤄요. 해석이 없는 예문만 기계 번역으로 해석을 붙여요 (하루 사용량 한도가 있어요).
- **예전에 찾은 단어:** 예전 버전에서 저장한 단어는 **설정 → 저장한 단어 N개 뜻·예문 새로 받기**로 한꺼번에 새로 받을 수 있어요. 퀴즈 기록과 직접 고친 뜻은 그대로예요.
- 뜻이나 예문이 마음에 안 들면 단어의 **수정**에서 고치면 돼요.
- 네이버·다음 사전은 외부 앱이 쓸 수 있는 공개 API가 없고, 케임브리지·옥스퍼드 사전 API는 유료 라이선스라서 쓰지 않아요. 사이트 내용을 자동으로 긁어 오는 것도 약관에서 막고 있어요.

### (선택) 유료 AI 사전

내 Claude API 키를 넣으면 Claude가 학습자 사전처럼 품사별 한국어 뜻, 쉬운 영영 풀이, 자연스러운 예문 3개를 만들어 줘요. 사용한 만큼 요금이 나가요 (Opus 5.5는 단어 하나에 1~2센트쯤, Haiku 5.5는 단어 100개에 5센트쯤). 키는 휴대폰 안에만 저장되고 Anthropic으로만 보내요. AI로 못 찾으면 무료 사전으로 찾아요.

1. [platform.claude.com](https://platform.claude.com/settings/keys)에 가입하고 로그인해요.
2. Settings → **Billing**에서 크레딧을 충전해요. Settings → **Limits**에서 한 달 사용 한도를 정해 두면 안심이에요.
3. Settings → **API keys**에서 **Create key**로 키를 만들어요 (키는 만들 때 한 번만 보여요).
4. 앱의 **설정 → 뜻·예문 찾는 방법**에서 **AI 사전**을 고르고, 키를 붙여 넣은 뒤 **키 확인**을 눌러요. "잘 돼요!"가 나오면 끝이에요.
5. 이미 저장한 단어는 같은 곳의 **단어 N개를 AI로 다시 찾기** 버튼으로 한꺼번에 AI 뜻·예문으로 바꿀 수 있어요 (누르기 전에 예상 요금을 보여 줘요).

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 모양 |
| `app.js` | 화면 동작 (찾기·단어장·퀴즈·알림·설정·백업) |
| `core.js` | 퀴즈 간격 계산, 퀴즈 문제 만들기, 알림 시간 계산 |
| `dict.js` | 뜻·예문 찾기 (무료 사전, AI) |
| `manifest.webmanifest` | 앱 이름, 아이콘, 전체 화면 설정 |
| `sw.js` | 오프라인 실행, 새 버전 안내, 알림을 누르면 단어 열기 |
| `icons/` | 홈 화면 아이콘 |

## GitHub에 올리기 (처음 한 번)

1. GitHub에서 **New repository** → 이름 예: `english-dictionary` → **Public** → Create.
2. **Add file → Upload files**로 이 폴더 안의 파일과 `icons` 폴더를 모두 올리고 Commit.
3. 저장소의 **Settings → Pages** → Branch를 `main`, 폴더를 `/ (root)`로 고르고 Save.
4. 1~2분 뒤 `https://sihuny227-rgb.github.io/english-dictionary/` 에서 열려요 (저장소 이름을 다르게 했으면 주소 끝도 그 이름이에요).

## 휴대폰에 설치하기

- **아이폰:** Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** Chrome으로 주소를 열고 ⋮ 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

## 기록은 어디에 저장되나요?

단어장과 퀴즈 기록은 각자의 휴대폰(브라우저) 안에만 저장되고 GitHub에는 올라가지 않습니다.
휴대폰을 바꾸거나 다른 기기로 옮길 때는 **설정 → 백업 파일 저장 / 백업 불러오기**를 쓰세요. 불러오면 지금 단어장에 합쳐지고, 같은 단어는 더 최근에 퀴즈를 푼 기록이 남아요. (API 키는 백업 파일에 들어가지 않아요.)

## 고친 뒤 다시 올리기

1. `sw.js` 맨 위의 `VERSION` 숫자를 하나 올립니다 (`my-english-dictionary-v1` → `my-english-dictionary-v2`).
2. 바뀐 파일을 GitHub에 다시 올립니다.
3. 설치된 앱을 다시 열면 "새 버전이 준비됐어요" 안내가 뜨고, **지금 적용**을 누르면 바뀝니다.
