      뜻·예문 찾는 방법

      API 키 만드는 법
      1. platform.claude.com에 가입하고 로그인해요.
      2. Settings → Billing에서 크레딧을 충전해요 (5달러면 Opus로 단어 수백 개, Haiku로는 수천 개).
      3. Settings → API keys에서 Create key를 눌러 키를 만들어요. 키는 만들 때 한 번만 보여요.
      4. 키(sk-ant-로 시작)를 복사해서 아래 칸에 붙여 넣고 키 확인을 눌러요.

      Settings → Limits에서 한 달 사용 한도를 정해 두면 안심이에요. 키는 다른 사람에게 보여 주지 마세요.

      Claude API 키 모델

      키는 이 휴대폰 안에만 저장되고 Anthropic(api.anthropic.com)으로만 보내요. 백업 파일에도 들어가지 않아요. AI로 못 찾으면 무료 사전으로 찾아요.

      무료 사전의 한국어 뜻은 위키낱말사전(ko.wiktionary.org, CC BY-SA)에서 가져와요. 발음 기호·영영 풀이는 dictionaryapi.dev, 예문은 Tatoeba를 쓰고, 사전에 없는 단어의 뜻과 예문 해석만 기계 번역(MyMemory)으로 채워요. 기계 번역은 하루 사용량에 한도가 있어요.
